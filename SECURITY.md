# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Complete Linux Installer (for example, an issue involving privilege boundaries, exported Android components, or archive extraction), please **do not** open a public GitHub issue.

Instead, please report it privately using one of the following options:
- **GitHub Private Vulnerability Reporting** (if enabled on the Security tab of this repository)
- Contact the maintainer directly via Discord (`discord.gg/QdT9yCrKmV`)

Please include:
- A clear description of the vulnerability and potential impact
- Steps to reproduce or a minimal proof of concept
- Your app version and device/Android version

We will acknowledge receipt and work with you on a fix before any public disclosure.
